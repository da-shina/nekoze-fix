# フォアグラウンドのみ＋画面暗転モードを採用する

バックグラウンド監視ではなく、フォアグラウンドで監視を継続しつつ画面を暗転させるモードを提供する。バックグラウンドでのカメラ使用はApp Store審査で正当な理由が必要であり、バッテリー消費も大幅に増加する。画面暗転モードにより、ユーザーはNekozeFixを開いたまま省電力で監視を継続できる。

## Considered Options

- バックグラウンド監視あり：App Store審査リスクとバッテリー問題
- フォアグラウンドのみ＋Split View前提：使い勝手が悪い
- フォアグラウンドのみ＋画面暗転モード（採用）：審査リスクなし、省電力
