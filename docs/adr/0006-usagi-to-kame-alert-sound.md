# デフォルト通知音に「うさぎとかめ」のメロディを使用する

内蔵通知音のデフォルトとして、童謡「うさぎとかめ」のメロディを短くカットしたものを使用する。作曲者（岡野貞一）は1941年没で著作権は消滅している可能性が高いが、自前で演奏・生成した音声ファイルを使用し、既存の録音物の著作権侵害を避ける。猫背通知として30秒間隔で再生されることを考慮し、長くても1-2秒程度の短いファンファーレに留める。

## Considered Options

- うさぎとかめのBGM継続再生：30秒間隔の要件と矛盾し、集中力を削ぐ
- うさぎとかめ風オリジナル通知音：著作権リスクは回避できるが、ユーザーの期待に合わない可能性

## 更新 (2026-09-12)

音源を第三者提供のチップチューン「うさぎとかめ」ループ音源（約14.2秒、商用利用可・編集可・クレジット表記任意）に差し替えたことに伴い、以下を変更する：

- **再通知間隔**: 固定30秒を廃止し、音声1ループ長（`AVAudioPlayer.duration`）に追従。猫背継続中は約14秒間隔のシームレスループ再生となり、結果として「BGM継続再生」寄りになったが、これは通知音としての機能（猫背の継続警告）を満たすため許容する
- **「1〜2秒のファンファーレ」要件**: 間隔が音源長に連動する設計に変更したため撤廃。短い音である必要はなくなった
