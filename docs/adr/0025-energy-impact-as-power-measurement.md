# 実機電力の計測に Xcode Debug navigator の Energy Impact を用いる

電力の実測手段として、対象機（iOS 18.7.7）で利用可能な Xcode 実機 Debug navigator の Energy Impact 指標を採用する。同一端末・同一セッションで通常時と暗転時を同条件で取得し、相対比較に用いる。校正電力（W / mAh）ではないため、絶対値や他セッション間の比較には用いない。

## 詳細

- 計測手段: Xcode の実機 Run 時に Debug navigator が表示する「Energy Impact」（`IDEIODebugGaugesCore` の `EnergyGauge`）。CPU・GPU・ネットワーク等の端末実測メトリクスから算出される相対指標であり、無計測の推計ではない。
- 比較則: 同一端末・同一セッション・同条件（同姿勢・同取得時間・同バックグラウンド状態）で通常時と暗転時を取得し、相対比較のみ行う。
- 未計測・推定の扱い: 取得していない消費電力・持続時間、および実測指標からの換算・外挿による推計は記録に含めない（要件7.2・8.2）。
- 記録: `measurements-4-2.md` の正準雛形の「電力」欄に、値＋計測手段＋条件（端末・OS・セッション・取得時間）を付して記す。

## 検討した選択肢

- Instruments Power Profiler: 校正電力が得られるが iOS 26.0 以上を要求し、対象機（iOS 18.7.7）では取得不可（却下）。
- 電池残量（%）の長時間差分計測: 実電力に近いが所要時間が長く、他要因の混入と分解能不足が大きい（却下）。
- 実測指標から消費電力への換算: 相関が未検証であり、要件7.2・8.2 の推定禁止に抵触する（却下）。
