# 通知音のプリロードタイミング

## 概要

確定判定から0.5秒以内に通知音を再生するため、 AlertPlayer のプリロードタイミングを「監視開始時」とする。

## 詳細

- `startMonitoring()` 呼び出し時に `AlertPlayer.configureSession()` と音声ファイルのロードを実行
- 監視停止時（ `stopMonitoring()` ）に `AlertPlayer` のリソースを解放
- 遅延ロード（初回再生前）は NFR 8.2（0.5秒以内再生）を満たせないリスクがある

## Considered Options

- 起動時プリロード: メモリ常駐だが、監視未開始時は不要リソースの消費
- 遅延ロード: 実装はシンプルだが初回再生遅延のリスク
- 観測開始前: ユーザーの校正 → 監視遷移時にロードできれば十分と判断
