# カメラプレビューのプリセット

## 概要

Vision キーポイント検出の精度とパフォーマンスのバランスを取るため、`AVCaptureSession.Preset.high` (720p) を使用する。

## 詳細

- プリセット `.high` は 1280x720 相当の解像度を提供し、Vision のキーポイント検出精度を向上させる。
- NFR 8.1（15fps以上）は `.high` でも達成可能（実機で確認済み）。
- バッテリー消費は `.medium` よりやや高くなるが、画面暗転モードと組み合わせることで総合的な消費を抑える。

## Considered Options

- `.medium` (540p): バッテリー優先だがキーポイント検出精度がやや低下（採用しなかった）
- `.vga640x480`: 過度に低解像度でキーポイント検出が不安定になる可能性
- 自動切替: 実装コストが高く、固定 `.high` で十分と判断
