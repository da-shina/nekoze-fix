# 耳-肩角度の計算と近側キーポイント決定規則

## 概要

耳-肩角度は「肩から耳へ向かうベクトルと画像上向きの垂直ベクトル(0, 1)の鋭角（0〜90度）」で定義する。画像座標系は左下原点・x右向き・y上向き。

## 近側キーポイント決定

画像の x 座標で判定する。画面左寄りのキーポイント（肩の x 座標が小さい側）を近側とする。正面設置の場合は左右とも同精度で同値となるため、片側を優先して近側とする。片側のみ検出時はその側を自動的に近側として扱う。

## 角度計算

ベクトル v = ear - shoulder と (0, 1) の内積から角度を算出。
cos(θ) = (v · (0, 1)) / (|v| * 1) = v.y / |v|
θ = acos(clamp(v.y / |v|, -1, 1))
結果は 0〜90度の鋭角として扱う（姿勢の前後どちらに倒れても角度増加として検知）。

## 判定ロジック

- 近側角度が基準角度 + 閾値以上 → slouchCandidate
- 近側のみ検出時はその値で判定
- 両側高信頼度時は近側角度を主指標、遠側角度は両側検出の有無の合否判定にのみ使用
- confidence < 0.5 のキーポイントは判定対象外

## Considered Options

- 鋭角のみ（採用）: クローズ/オープン両方を角度増加として検知可能、シンプル
- 0〜180度: 方向を区別できるが判定条件が複雑化
- 移動平均フィルタ: 5秒ゲートで十分と判断し省略
- 片側判定時の近側自動決定: 片側検出時はその側を近側とする（シンプル化）
