# 耳-肩角度の計算と近側キーポイント決定規則

## 概要

耳-肩角度は「肩から耳へ向かうベクトルと基準上向きベクトルの鋭角（0〜90度）」で定義する。基準上向きベクトルは両肩検出時は両肩ライン直交上向き法線ベクトルとし、片肩のみ検出時は画像上向き垂直ベクトル(0, 1)とする。画像座標系は左下原点・x右向き・y上向き。

## 近側キーポイント決定

画像の x 座標で判定する。画面左寄りのキーポイント（肩の x 座標が小さい側）を近側とする。正面設置の場合は左右とも同精度で同値となるため、片側を優先して近側とする。片側のみ検出時はその側を自動的に近側として扱う。

## アスペクト比補正

Vision 正規化座標は非正方形フレームでも [0,1]×[0,1] に正規化されるため、x/y のスケールが異なる。4:3 フレームでは正規化座標の肩ベクトル (0.4, 0.1) は画像座標で約 3.4° の角度ズレを生じる。

角度計算前に x 成分に 1/AR（AR = 画像幅/画像高）を適用して等方座標系に変換する。これにより PostureOverlayView の画面座標計算と角度が一致する。距離指標はパーセント比較のため正規化座標のまま変更しない。

## 角度計算

両肩キーポイントが有効な場合、左肩から右肩へのベクトル (sdx, sdy)（sdx >= 0）の x 成分に 1/AR を適用した後、直交法線ベクトル perp = (-sdy, sdx') / |s'| を基準軸とする（両肩が水平なら perp = (0, 1) と一致）。片側のみ検出時は perp = (0, 1) とする。
ベクトル v = ear - shoulder も x 成分に 1/AR を適用した後、perp との内積から角度を算出。
cos(θ) = (v' · perp) / (|v'| * 1)
θ = acos(clamp(cos(θ), -1, 1))
結果は 0〜90度の鋭角として扱う（姿勢の前後どちらに倒れても角度増加として検知）。体幹（両肩）が左右に傾いた場合でも、首自体が曲がっていなければ猫背と誤認されない。

## 判定ロジック

- 近側角度が基準角度 + 閾値以上 → slouchCandidate
- 近側のみ検出時はその値で判定
- 両側高信頼度時は近側角度を主指標、遠側角度は両側検出の有無の合否判定にのみ使用
- confidence < 0.5 のキーポイントは判定対象外

## Considered Options

- 鋭角のみ（採用）: クローズ/オープン両方を角度増加として検知可能、シンプル
- 0〜180度: 方向を区別できるが判定条件が複雑化
- 移動平均フィルタ: 5秒ゲートで十分と判断し省略
- 片側判定時の近側自動決定: 片側検出時はその側を近側とする（シンプル化）
