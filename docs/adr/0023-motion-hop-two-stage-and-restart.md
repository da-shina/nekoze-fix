# 重力hop二段比較と即時再開則

## 概要

重力取得（`MotionService`）の毎サンプル `Main` hop（30Hz固定）を削減するため、取得経路に二段比較（background粗比較→Main公開値更新抑制）を導入し、頻度切替は動作中も即時再開で反映する。判定・保持・変換・代替鎖・起停契約は変えない。

## 用語定義

- **重力取得頻度**：端末計測機能から重力を取得する頻度（CONTEXT.md正準）。毎秒30回・15回・10回の候補、既定は毎秒30回
- **公開値**：`latestGravityInKeypointSpace` の値。判定は読取り時に最新公開値を使用する（受動公開・pull）
- **受信回数**：端末計測機能からの重力サンプル到着回数（`motionSamples`）
- **公開値更新回数**：実質変化・状態変化により公開値を書替えた回数（`motionVisible`）
- **最終hop済み値（lastSent）**：background側が最後にhopした変換済み値。送信要否の比較基準であり、保持・ホールド則の状態ではない

## 詳細

- 二段比較（Q2=C・Q9一本化）：`motionQueue`（直列）側で `convert`（純関数のためスレッド安全）→最終hop済み値とのユークリッド距離比較→実質同一ならhop自体を起こさない。単一許容差に一本化し二重閾値を作らない。許容差は暫定 `1e-4` とし、事前分布計測（`00-gravity-noise`：机置き・手持ち静止各5分＋動作、`|Δu|` p50/p95/max、`ノイズp99 < ε < 動作p5`）で確定する。空なら暫定のまま tasks 5.1 で事後検証する
- Main側抑制（Q10=A）：Main側は既存ホールド則のみ残す。`lastSent` はbackground所有（送信成否のみ）、`lastValidVector/lastValidTime/公開値` はMain所有のまま。受渡しは値渡しのみで二重状態の意味を分ける
- 無効則（Q14）：無効（`convert==nil`・生値なし含む）の到着は全てhopする。無効継続の公開値変化はMain側時刻依存でbackgroundから見えず、無効連続は平置き等の稀経路のため削減効果が薄い。単純化で状態変化漏れを消す
- 破棄則（Q15）：`stop()` 時に `lastSent` もnilクリアし、次回 `start` 初回は無条件hopとする。再開直後の偶然一致による誤抑制を防ぐ
- 即時再開則（Q5=A・Q11）：`setUpdateFrequency` は `isRunning==true` のみ `stop→新interval→start` を原子的に行い、`false` 時は次回 `start` まで遅延反映する。`setMotionRotationRunning` の契約・順序は変えない。暗転継続中は即時再開扱い、背景停止後は遅延反映扱いになる
- 頻度候補（Q4）：`thirtyHz/fifteenHz/tenHz` の3値enumに閉じ、許可外は既定維持とする。将来拡張は本ADRの再検証を要する
- 保持則（Q7）：0.5秒単一ホールド・変換・代替鎖は不変。低頻度時の期限評価遅延（最大0.1秒）を受容し全頻度で回帰する
- 計測（Q6/Q13/Q17）：所有は `MotionService`、メモリ内のみ。`motionSamples/motionVisible/motionReads/motionInvalidReads` を既存 `[NekozeFix Metrics]` 同一行に同梱し `/tmp/nekoze-measure/07-motion-*` に保存する。各頻度5分×3シナリオ＋判定一致100%、電力定量差なし／精度差1件でも見送り

## 検討した選択肢

- hop維持＋公開値書込みのみ抑制：変更最小だがhop自体が残り省電力の主因を消せない（却下、Cの二段比較を採用）
- background生値比較（変換前差分）：変換前後で閾値が別物になり二重閾値化する（却下、変換後一本化を採用）
- 全状態のbackground移管：`ingest` 入口契約と `@MainActor` 保持則を壊し回帰が重い（却下、所有分離を採用）
- 許可外頻度の黙示受容・連続値指定：検証範囲が無限化する（却下、3値閉集合を採用）
- 次回開始時反映のみ：暗転継続（再開なし）中の率低下が効かず Req 6.5 を形骸化させる（却下、即時再開を採用）
- 無効継続の抑制：backgroundから公開値変化が見えず漏れの恐れがあり、削減効果も薄い（却下、全数hopを採用）
- 保持期限のタイマ駆動化：3秒確定に対する影響が無視できる範囲であり機構追加に見合わない（却下）
