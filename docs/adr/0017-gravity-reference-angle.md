# 重力基準への一本化

耳-肩角度の主基準を両肩ライン直交から、天方向（端末計測の重力反対方向を画像座標に投影した向き）に一本化する。肩の傾き吸収よりも前屈の絶対量を直接測ることを優先し、判定・校正・表示を同一基準に統一する。重力計測が利用できない間に限り両肩ライン直交を代替基準とする。

## Considered Options

- 両肩ライン直交を主基準に維持：体幹の左右傾きを吸収できるが、肩自体が傾くと前屈を見逃す
- 画像上向き固定：端末固定前提では単純だが、設置傾きの誤差が残る
- 天方向一本化（採用）：片側・両側検出で基準が変わらず、設置傾きに追従する

## Consequences

- 端末の傾き計測への依存が生じ、取得不能時の代替切替と復帰の扱いが設計で必要になる
- 回転中や切替過渡の振動対策（猶予・ヒステリシス）は設計で定める
- ADR-0008 は主基準としては superseded、代替基準の定義のみ残す
