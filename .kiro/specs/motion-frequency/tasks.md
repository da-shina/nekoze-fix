# Implementation Plan

- [ ] 1. 計測基盤となる値オブジェクトを追加する
  - 取得頻度の候補（毎秒30回・15回・10回）と取得間隔の対応を列挙として定義する
  - 計測結果（頻度・計測期間・受信回数・可視値更新回数（dispatchCount）・消費参照回数・無効参照回数・計測条件）を変更不可の値として定義する
  - 計測結果に推定値を含めない形式であることが型で表せている
  - _Requirements: 1.1, 1.2, 1.3, 7.3_

- [ ] 2. 取得間隔と可視値更新抑制と計測を改善する
- [ ] 2.1 取得間隔を内部設定化し許可値を検証する
  - 既定の取得間隔を毎秒30回とし、候補外の指定では既定を維持して頻度変更を追加しない
  - 設定が次回開始時から取得に反映され、保持・変換・起停の既存則が変わらない
  - 許可外指定時の既定維持が検証で確認できている
  - _Boundary: MotionService拡張_
  - _Requirements: 2.1, 2.3, 3.1, 6.5, 7.4_
- [ ] 2.2 同一値受信時の可視値更新抑制則を導入する（受動公開・pull）
  - 前回受信値との許容差付き比較で実質同一の場合のみ可視値の更新を抑制する（Sessionへの通知は行わない）
  - 値の変化時と有効・無効の状態変化時は必ず可視値を更新する
  - 抑制時も判定結果が変わらないことが検証で確認できている
  - _Boundary: MotionService拡張_
  - _Requirements: 3.3, 3.4_
- [ ] 2.3 区間計測のカウンタを所有させる
  - 受信回数・可視値更新回数（dispatchCount）・消費参照回数・無効参照回数を区間ごとに数える
  - 計測の開始・終了・取出しを提供し、未終了区間の取出しを許さない
  - 計測状態が取得・判定の動作に影響しないことが確認できている
  - _Boundary: MotionService拡張_
  - _Requirements: 1.1, 1.2, 1.3_

- [ ] 3. 消費時の参照記録を判定読取りに付随させる
  - 最新値の読取り則は変えず、読取りのつど参照の有無を計測側へ通知する
  - 通知漏れがあっても判定結果に影響しない順序で組み込む
  - 参照回数と判定実行回数が一致することが検証で確認できている
  - _Boundary: Session消費記録_
  - _Depends: 2.3_
  - _Requirements: 1.1, 2.2, 3.2_

- [ ] 4. 新規検証の追加と既存回帰の再実行
- [ ] 4.1 新規振る舞いの検証を追加する
  - 頻度設定・可視値更新抑制則・計測カウンタ・参照記録の一致を検証する
  - 状態変化時の可視値更新漏れがないことを検証する
  - 新規検証がすべて成功することが確認できている
  - _Boundary: MotionService拡張, Session消費記録_
  - _Depends: 2.1, 2.2, 2.3, 3_
  - _Requirements: 1.1, 1.2, 1.3, 2.1, 2.3, 3.1, 3.2, 3.3, 3.4, 6.5, 7.4_
- [ ] 4.2 (P) 既存回帰を全頻度条件で再実行する
  - ホールド境界・変換・平置き無効・起停の既存検証を毎秒30回・15回・10回の各設定で再実行する
  - 代替鎖への退行と復帰・回転中の停止と再開・鏡像の扱い・3秒確定則の意味が保たれることを確認する
  - 映像取得・推論の動作と閾値・選択則に変更がないことを確認する
  - すべての既存検証が成功することが確認できている
  - _Boundary: PostureAnalyzer, DeviceRotationService, 既存起停・代替表示_
  - _Requirements: 4.1, 4.2, 4.3, 4.4, 4.5, 4.6, 5.1, 5.2, 5.3, 5.4, 5.5, 5.6, 6.1, 6.2, 6.3, 6.4, 7.1, 7.2_

- [ ] 5. 実機計測と比較選定を確定する
- [ ] 5.1 候補頻度での実機計測と記録を行う
  - 毎秒30回・15回・10回の各条件で電力と判定精度を実測し、計測条件を付して記録する
  - 実測していない省電力率や持続時間を記載せず、未計測項目を明記する
  - 比較に必要な実測が記録として揃っている
  - _Requirements: 2.1, 2.2, 2.4, 7.3_
- [ ] 5.2 精度回帰と選定・見送り判断を確定する
  - 実機で回転追従・復帰時間・3秒確定則の意味を確認し、判定の一致を確かめる
  - 電力改善が実測で確認できない場合または実測が不足する場合は現状頻度を維持し変更を追加しない
  - 選定または見送りの判断と根拠となる実測値が記録として残っている
  - _Requirements: 2.3, 2.4, 4.6, 7.4_
