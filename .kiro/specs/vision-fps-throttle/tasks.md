# Implementation Plan

- [ ] 1. 間引き判定器の基盤実装
- [ ] 1.1 時刻間隔による推論対象選定の実装
  - 提示時刻の間隔が上限間隔以上の場合のみ推論対象とする判定を実装する
  - 無効時刻のフレームは推論対象として扱い検出機会を保つ
  - 上限間隔の初期値は注入時に定まることを単体で確認できる
  - 新規ファイルをXcodeターゲットに追加しビルドが通る
  - _Boundary: FrameThrottle_
  - _Requirements: 2.1, 2.2, 2.3, 2.4, 3.2, 5.1, 5.2_
- [ ] 1.2 計数と初期化と読出しの実装
  - 入力到達数・推論実行数・破棄数・推論累積時間を保持する
  - 停止・再開時に判定状態を初期化できる
  - 計測値は複写で読み出せて永続化と外部送出を行わない
  - 計測の有無で検出結果と呼出順序が変わらないことを確認できる
  - _Boundary: FrameThrottle_
  - _Requirements: 1.1, 1.2, 1.3, 6.1_
- [ ] 1.3 上限切替え受口の実装
  - `setLimit(_:)` で判定中の上限切替えを受け付け前回推論時刻を維持したまま次回判定から新上限間隔を適用する
  - 切替えは検出キュー経由の直列適用とし判定途中での割込みを起こさない（dim-mode-savingからの切替え受口）
  - _Depends: 1.1_
  - _Boundary: FrameThrottle_
  - _Requirements: 2.3, 5.1, 5.2_

- [ ] 2. 呼出点への結線
- [ ] 2.1 呼出点先頭へのゲート結線
  - 検出実行の直前で判定し対象外フレームを破棄する
  - 通過フレームのみを顔条件付き実行の判定対象として渡し順序を保つ
  - 推論待ちの無制限蓄積を作らず遅延破棄の既存運用を維持する
  - 検出実行場所と結果受け渡しの振る舞いが変わらないことを確認できる
  - _Depends: 1.1_
  - _Boundary: PostureSessionManager呼出点_
  - _Requirements: 2.1, 2.4, 3.1, 3.3, 6.2, 6.3, 6.4_
- [ ] 2.2 停止・再開経路からの初期化配送
  - カメラ停止・再開時に判定状態の初期化を検出キューへ配送し、同一キュー上で「FrameThrottle.reset() → MainHopGate.reset()」の順に直列実行する（順序の正本は本タスクとし、mainactor-throttle側の二重リセット順序は本タスクを参照する）
  - 再開直後の過剰破棄や古い状態による判定の乱れが起きないことを確認できる
  - _Boundary: PostureSessionManager呼出点_
  - _Requirements: 6.1_
