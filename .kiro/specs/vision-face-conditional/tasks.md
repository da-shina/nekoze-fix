# Implementation Plan

- [ ] 1. 姿勢優先の条件実行の実装
- [ ] 1.1 姿勢フェーズの単独実行に分割する
  - 姿勢検出のみを先行実行し、観測の有無で後続を分岐できる形にする
  - 姿勢観測ありの場合は顔推論を実行せず姿勢結果を確定できること
  - 完了状態: 姿勢有効フレームで顔推論が実行されないことが呼び出し結果から確認できる
  - _Boundary: PoseDetector_
  - _Requirements: 1.1, 1.2, 1.3_
- [ ] 1.2 観測ゼロ件時の顔フォールバックを結合する
  - 姿勢観測ゼロ件の場合のみ顔検出を実行し、現行と同一の3値意味で合成する
  - 顔のみ検出時は人物あり姿勢不明、両方なし時は人物不在となること
  - 複数人時は画面中央の人物選択則が維持されること
  - 完了状態: 姿勢なし・顔あり・両方なしの各入力で現行と同一の判定区分が返る
  - _Boundary: PoseDetector_
  - _Requirements: 2.1, 2.2, 2.3, 2.4, 6.1, 6.3_
- [ ] 1.3 両経路の推論回数と推論時間の記録を追加する
  - 顔省略回数・顔実行回数・各フェーズの累積推論時間を錠で保護して保持する
  - 検出結果自体は計測の有無で変化しないこと
  - 読み出しは複写で行い、永続化と外部送出を行わないこと
  - 完了状態: 成功経路と失敗経路の回数・時間が区別して読み出せる
  - _Boundary: PoseDetector_
  - _Requirements: 5.1, 5.2, 5.3, 5.4_

- [ ] 2. 検証の追加と回帰確認
- [ ] 2.1 (P) 条件分岐と計数の単体検証を追加する
  - 姿勢有効時の顔省略、観測ゼロ件時の顔実行、両方なし時の人物不在を検証する
  - 成功経路と失敗経路で対応する計数が進むことを検証する
  - ファイル編集は検出層の検証範囲に留め、他範囲の検証ファイルには触れないこと
  - 完了状態: 新規検証がすべて成功し、既存の検出層検証も成功し続ける
  - _Boundary: PoseDetectorTests_
  - _Depends: 1.1, 1.2, 1.3_
  - _Requirements: 1.1, 1.2, 2.1, 2.2, 2.3, 5.1, 5.2_
- [ ] 2.2 (P) 既存の検出・セッション回帰を再実行する
  - 人物不在警告・信頼度閾値・片側継続・近側選択・校正監視遷移の既存検証を再実行する
  - 本タスクでは検証ファイルの編集を行わず、実行と結果確認のみ行う（2.1との並列安全性の根拠）
  - 完了状態: 既存の全関連検証が成功し、振る舞い変更がないことが確認できる
  - _Boundary: PostureSessionManagerTests_
  - _Depends: 1.1, 1.2_
  - _Requirements: 3.1, 3.2, 3.3, 3.4, 3.5, 4.1, 4.2, 4.3, 4.4, 4.5, 6.1, 6.2_

- [ ] 3. 実機での両経路計測と効果記録
- [ ] 3.1 実機で成功経路と失敗経路の推論回数・時間を記録する
  - 実機と接続端末が必要な前提であり、 simulate では代替しないこと
  - 通常姿勢での省略発生と接写俯き等での顔フォールバック発生の双方を実測すること
